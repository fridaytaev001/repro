Transitive dependencies remain subject to their own package licenses. Chromium and Playwright's Node/FFmpeg tooling are installed separately by the official Playwright installer; they are not copied into the public source repository. Crusoe is an external inference service rather than bundled model weights. All local keys, browser downloads, run data, recorded media, and evidence bundles are ignored by Git.

The FIELD visual is original HTML/CSS, not a downloaded product photograph. The target's seeded fault is disclosed. Integration references include Crusoe's official developer hub and docs, plus Playwright and FastAPI documentation.

No separate project-wide license grant has been selected for this repository; public visibility alone does not relicense third-party dependencies or grant additional rights to the Repro source. Choose a project license before wider reuse if needed.
