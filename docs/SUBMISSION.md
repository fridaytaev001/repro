## Copy-ready description

Repro turns a vague website complaint into independently verified reproduction steps, runnable tests, browser evidence, and a proposed source patch with protected before-and-after proof. A Crusoe-powered investigator tries experiments against an original synthetic checkout. Ordinary code freezes checks and bounds actions; an independent clean-browser verifier must observe a documented-rule violation before confirmation. A separate repair loop can change only an isolated source copy. Its frozen regression must fail on baseline and pass on candidate, alongside controls, before the UI calls the isolated repair verified.

Measured evidence includes a real discount-state bug, correct rejection of an ineligible coupon, recovery from remembered steps that did not reproduce the problem, and a live Crusoe repair. The model used was `deepseek-ai/Deepseek-V4-Flash`, selected from the live catalog. Recorded walkthroughs and saved evidence are explicitly labelled; tests with scripted providers are not represented as live inference.
